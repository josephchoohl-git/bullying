# Kind Choices, Safe Friends

A P3 bullying psychoeducation deck for a small-group session (2 students, about 40 to 45 minutes) led by a school counsellor. It is written to build understanding and empathy **without labelling or penalising** the students: the lesson follows three fictional classmates (Ben, Mei Ling and Hari) so students can discuss hurtful choices at a safe distance.

## Approach

- Framework: Choice Theory / Reality Therapy (needs in child language, WDEP-style closing plan).
- Resources consulted: a secondary-school bullying awareness deck and the *Eyes on Bullying* toolkit (Education Development Center, 2008), adapted for P3 in Singapore.
- Visual style: “Scatterbrain” sticky-note and cork-board design (Shrikhand, Zilla Slab, Caveat).
